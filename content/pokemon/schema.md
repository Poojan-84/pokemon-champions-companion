# Pokémon entry schema

Each Pokémon is one JSON file in `/content/pokemon/`, named `<id>.json` (e.g. `garchomp.json`).

## Shape

```json
{
  "id": "garchomp",
  "nationalDexNumber": 445,
  "name": "Garchomp",
  "types": ["Dragon", "Ground"],
  "baseStats": { "hp": 108, "atk": 130, "def": 95, "spAtk": 80, "spDef": 85, "spe": 102 },
  "abilities": ["Sand Veil", "Rough Skin"],
  "spriteUrl": "from PokeAPI",
  "regulation": { "legal": true, "current": "M-B" },
  "tier": "S",
  "role": "Physical Attacker",
  "commonMoves": ["Earthquake", "Dragon Claw", "Rock Slide", "Swords Dance"],
  "commonItems": ["Life Orb", "Choice Scarf"],
  "summary": "One or two sentences a first-timer can read in 10 seconds",
  "relatedGuideSlugs": ["dragon-teams-archetype"]
}
```

## Field notes

| Field | Source | Notes |
|---|---|---|
| `id` | derived | Kebab-case slug, matches the filename and the PokeAPI pokemon name (e.g. `floette-eternal`). |
| `nationalDexNumber` | PokeAPI | Pulled automatically. Do not hand-edit. |
| `name` | PokeAPI | Pulled automatically. Do not hand-edit. |
| `types` | PokeAPI | Pulled automatically. Do not hand-edit. |
| `baseStats` | PokeAPI | Pulled automatically. Do not hand-edit. |
| `abilities` | PokeAPI | Pulled automatically. Do not hand-edit. |
| `spriteUrl` | PokeAPI | Pulled automatically. Do not hand-edit. |
| `regulation` | hand-curated | `legal` (boolean) and `current` (regulation code, e.g. `"M-B"`). PokeAPI has no knowledge of Champions regulations — we track this ourselves. |
| `tier` | hand-curated | One of `S` / `A` / `B` / `C` / `D`. |
| `role` | hand-curated | Short label, e.g. `"Physical Attacker"`, `"Support"`. |
| `commonMoves` | hand-curated | The moveset players actually run in the current meta, not the full learnset. |
| `commonItems` | hand-curated | The items players actually run in the current meta. |
| `summary` | hand-curated | **Max ~2 sentences.** This is what renders on the card view (30-second rule — see VISION.md), not a stats dump. Longer competitive detail belongs on a dedicated guide page, not here. |
| `relatedGuideSlugs` | hand-curated | Slugs of related guide pages for internal linking (SEO). |

## Curated vs. generated fields

- **PokeAPI fields** (`nationalDexNumber`, `name`, `types`, `baseStats`, `abilities`, `spriteUrl`): sourced from [PokeAPI](https://pokeapi.co), regenerated by `/scripts/fetch-pokemon.ts`. Never hand-edit these — rerun the script instead if they need to change.
- **Curated fields** (`regulation`, `tier`, `role`, `commonMoves`, `commonItems`, `summary`, `relatedGuideSlugs`): PokeAPI has no knowledge of Pokémon Champions competitive play. These are researched and written by us. See [DECISION_LOG.md](../../docs/DECISION_LOG.md) — "Data sourcing: PokeAPI + hand-curated competitive data."
- **Starter files**: `/scripts/fetch-pokemon.ts` generates a starter JSON with PokeAPI fields filled in and curated fields left as empty placeholders (`""`, `[]`, `null`) — fill those in by hand before publishing the entry.
